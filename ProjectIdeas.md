# Ideas

## AI Agent for trading
This idea is somehow straight forward, build a service that is based on an AI Agent that calculate trading strategies in real time and rank them in order to chose the best one to execute in a given time frame and a given capital and a given entry and a stop loss

* The AI agent connects to the different plateformes.
* The AI agent read the input data to be used for trading.
  * Capital.
  * Trading pairs.
  * Trading Goals.
  * Strategies.
* The AI Agent then executes the algorithm that will give the best strategies based on different parameters in real time.
* The AI Agent decides based on the outcome to continue of withdraw from the trade and or the strategy.
* The AI Agent may try to apply a different strategy based on the changes in the market.
